# Web UI Template Collection

A collaborative collection of modern and responsive Web UI templates developed using HTML, CSS, and JavaScript.

This project contains UI templates from four categories:

- Food
- Movies
- Shopping
- Music

The main purpose of this project is to learn modern web UI development and GitHub collaboration through a team-based workflow.

## GitHub Collaboration Workflow

The project follows a collaborative GitHub workflow.

Fork → Clone → Create Branch → Develop → Commit → Push → Pull Request → Review → Merge

Each team member works on their assigned category using a separate branch.

After completing the work, the member pushes the branch to GitHub and creates a Pull Request.

The Pull Request is reviewed before the changes are merged into the main project.

This workflow helps the team avoid directly making all changes on the main branch and provides practical experience with GitHub collaboration.

## How to Run the Project

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in a modern web browser.
